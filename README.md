# JrVisual

Interface web responsiva desenvolvida em TypeScript, com foco em adaptação para dispositivos móveis, organização visual e experiência do usuário.

**Demo:** [Acessar aplicação](https://mobile-website-adaptation-iota.vercel.app)

## Tecnologias

- TypeScript
- Vite
- Git e GitHub
- Vercel

## Funcionalidades

- Interface adaptada para diferentes tamanhos de tela
- Estrutura de projeto moderna com Vite e TypeScript
- Aplicação publicada na Vercel

## Como executar localmente

Pré-requisito: Node.js instalado.

```bash
git clone https://github.com/spray-dev/jrvisual.git
cd jrvisual
npm install
npm run dev
```

Em seguida, abra no navegador o endereço exibido pelo Vite.
